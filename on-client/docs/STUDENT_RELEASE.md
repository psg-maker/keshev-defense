## 2. 확인 방식 구분

| 구분 | 뜻 |
|---|---|
| 시연(예제) | `npm.cmd run demo`의 내장 예제 엔진으로 화면을 본 것. 실제 연결 아님 |
| 실제 실행 | 기본 실행 또는 실제 연동 시스템에 연결해 결과를 받은 것 |
| 학생 진술 | 학생이 직접 보고 적은 결과. 서버가 실행해 확인한 것이 아님 |

| 원문 확인 | 코드·문서를 읽어 확인한 것(실행 안 함) |
| 미확인 | 실행하지 못했거나 결과를 받지 못한 것 |

## 5. 이동 가능한 구성

- 새 환경에 필요한 것: Node.js 22~24(기준 24.19.0), Git, 이 저장소. 외부 npm 의존성이 없어 `npm install`이 필요 없습니다.
- 설정 견본: `on-client/.env.example`(비밀 없음). 포트는 환경변수 `ON_PORT`(기본 5189)로 바꿉니다. 서버는 `.env` 파일을 자동으로 읽지 않으므로 필요하면 PowerShell에서 `$env:ON_PORT = '5190'`처럼 지정합니다(원문 확인, 실행 미확인).
- 실행 코드는 로컬 절대경로에 의존하지 않습니다. 경로는 모두 앱 폴더 기준 상대경로입니다(원문 확인). 문서의 PC 경로는 예시입니다.
- 비밀값(AI 앱 자격, native 설정, SDP 인증서·개인키)은 저장소·제출물에 없습니다. 새 환경에서는 운영자 안내에 따라 다시 준비하며, 기존 PC에서 복사하지 않습니다.
